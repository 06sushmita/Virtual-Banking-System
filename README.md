# Virtual Banking System

A **Virtual Banking System** built using **Spring Boot**, **MySQL**, and **HTML/CSS/JavaScript** that simulates core banking operations such as user authentication, transactions, passbook history, notifications, and admin management.

---

##  Features

###  User Module
- User Registration & Login
- Secure Authentication
- View Account Dashboard
- Balance Inquiry
- Fund Transfer
- Transaction History (Passbook)
- Notifications for Transactions

###  Admin Module
- Admin Login
- View All Users
- View All Transactions
- Monitor System Activities
